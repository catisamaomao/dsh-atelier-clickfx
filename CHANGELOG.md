# Changelog

## 1.1.0

- Publish an independent, ready-to-install DSH plugin package with native plugin-list localization.
- Add English, Simplified Chinese, Traditional Chinese, Japanese and Russian metadata and preview text.
- Add paired English/Chinese documentation and cross-platform installation commands.
- Add Node 22/24 CI across macOS, Windows and Linux, plus package and lifecycle regression checks.
- Preserve the locally verified 720 ms gold ripple and star renderer from 1.0.0.

## 1.0.0

- Initial local release for DeepSeek Harness 0.2.0-rc.2 and the Maid Atelier skin.
- Add theme-aware colors, passive pointer handling, drag filtering, reduced-motion support and complete disposal.
